模型推理

gen_ai.inference.client

该 span 表示对生成式 AI 模型或服务的客户端调用，它根据输入提示词生成响应或请求工具调用。

命名：span 名宜为 {gen_ai.operation.name} {gen_ai.request.model}。针对各个 GenAI 系统和框架的语义约定可以规定不同的 span 名称格式，但必须遵循 OTel 的 span 命名总体准则。

gen_ai.operation.namestring必填

正在执行的操作名称。

development
说明、取值与示例

本 Span 取值（规范示例）：chat · generate_content · text_completion

其他操作使用的全局枚举值：embeddings · retrieval · fetch_response · create_agent · invoke_agent · execute_tool · invoke_workflow · plan · search_memory · create_memory · update_memory · upsert_memory · delete_memory · create_memory_store · delete_memory_store

chat 聊天补全操作，例如 OpenAI Chat API
generate_content 多模态内容生成操作，例如 Gemini Generate Content
text_completion 文本补全操作，例如 OpenAI Completions API（旧版）
embeddings 嵌入操作，例如 OpenAI Create embeddings API
retrieval 检索操作，例如 OpenAI Search Vector Store API
fetch_response 按标识符取回此前生成的模型响应，不执行推理，例如 OpenAI Get a model response
create_agent 创建 GenAI agent
invoke_agent 调用 GenAI agent
execute_tool 执行工具
invoke_workflow 调用 GenAI 工作流
plan Agent 规划或任务分解阶段
search_memory 从记忆存储中搜索 / 查询记忆
create_memory 创建新的记忆记录
update_memory 更新已有记忆记录
upsert_memory 创建或更新记忆记录（由实现决定是创建还是更新，调用方不指定）
delete_memory 删除记忆记录
create_memory_store 创建或初始化记忆存储
delete_memory_store 删除或下线记忆存储

若适用某个预定义取值，但特定系统使用了不同名称，推荐在特定 GenAI 系统的语义约定中记录该名称，并在埋点库中使用系统特定名称。若未记录不同的名称，埋点库宜使用适用的预定义取值。

库按 id 取回已生成的响应，不做推理

openai · reference/scenarios/openai/scenario.py

  • 取回已存储的响应：先用 create(..., store=True) 生成并保存一条响应，再按 id 取回。那次 create 属于推理操作，不包进本条 span —— span 只覆盖 retrieve 这一次调用，字段值也都取自这个调用边界。
  • 后台流式响应中断后从断点续取：用 background=True、stream=True 创建响应，消费到调用方断开后记下最后一个事件的 sequence_number，再用它（OpenAI 的 starting_after / Google 的 last_event_id）续取；该游标记入 gen_ai.request.stream_cursor。
  • 取回原始生成失败的响应：取回本身是成功的，失败只体现在内容里：status=failed 推导出 finish_reasons=[error]。这次 fetch 不设 error.type、span 也不标 ERROR；仍在 queued / in_progress 的响应则没有 finish reason。
